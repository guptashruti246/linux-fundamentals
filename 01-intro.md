# Introduction to Linux

---

## What is Linux?

Linux is an open-source operating system that acts as a bridge between hardware and software.

It allows users to interact with the system using commands.

---

## Where is Linux used?

Linux is widely used in:

- Servers (most websites run on Linux)
- Cloud platforms (AWS, Azure, GCP)
- DevOps environments
- Android (based on Linux kernel)

---

## Why should we learn Linux?

- Most DevOps tools run on Linux
- Required for cloud and server management
- Helps in automation and scripting

---

## What is a Terminal?

The terminal is a command-line interface where we type commands to interact with the system.

Unlike Windows (GUI), Linux is heavily command-based.

---

## Linux Architecture (Simple View)

Linux works in layers:
### 1. Hardware
- Physical components like CPU, RAM, Disk
- Executes actual operations

---

### 2. Kernel (Core of Linux)
- The heart of the operating system
- Manages hardware resources
- Handles memory, CPU, devices, and processes

👉 It connects software with hardware

---

### 3. Shell
- Interface between user and kernel
- Takes user commands and passes them to kernel

Examples:
- bash
- sh

---

### 4. User
- The person interacting with the system
- Uses terminal or GUI to give commands

---

## Key Concepts

- Everything in Linux is treated as a file
- Linux is case-sensitive
